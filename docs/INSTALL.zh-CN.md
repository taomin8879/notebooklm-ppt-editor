# 安装与使用说明

NotebookLM PPT Editor — 安装与使用说明
版本：0.1.0 / build 186
安装包适用：Apple 芯片 Mac（M 系列），macOS 13 或更高版本

一、这是什么

把 NotebookLM 导出的图片型 PDF、PPTX 或幻灯片截图转换为可编辑文字的 PowerPoint。
这是独立工具，与 Google / NotebookLM 无官方关联。

本安装包包含完整桌面 App、Python 运行环境、OCR 模型、背景修复模型和字体资源。
你不需要安装 Python、命令行工具或 AI Skill，也不需要下载模型。
目前不支持 Windows 和 Intel Mac。

二、安装（第一次使用）

1. 双击 DMG 安装包。
2. 把“NotebookLM PPT Editor.app”拖到同窗口的“Applications”文件夹。
3. 若已有同名应用，先退出旧版并备份工作资料，确认后再替换。
4. 安装免费的 LibreOffice，供软件渲染和核对转换结果：
   官方下载入口：https://www.libreoffice.org/download/download-libreoffice/
   请按官网提示选择适合自己系统的 Apple 芯片版。
5. 从“应用程序”打开 NotebookLM PPT Editor。
6. 使用完安装窗口后，可在 Finder 中推出安装磁盘。

注意：本版为临时签名，尚未取得 Apple Developer ID 签名和 Apple 公证。
从网络下载到另一台 Mac 时，系统可能阻止首次打开。
仅在确认文件来自可信作者、校验值一致且理解风险后，按系统提示决定是否允许该应用打开。
如显示恶意软件或文件损坏等警告，请先停止并联系提供者，不要关闭 Gatekeeper 或执行批量移除安全标记的命令。

三、开始转换

1. 将 PDF、PPTX、PNG、JPG/JPEG 拖入窗口，或点击“选择文件”。
2. 选择需要转换的页码。建议先试转一页，确认效果后再转换整份文件。
3. 检查“输出位置”。默认目标是下载文件夹，也可自行选择；应用会记住你选择的位置。
4. 默认可使用本地模式，不需要 API Key。
5. 点击“开始转换”，等待处理结束，不要重复启动相同任务。
6. 根据完成界面打开 PPTX、检查图和质量报告。

最终文件路径以应用的完成界面为准。不要把中间工作目录当成永久归档，重要结果请自行备份。

四、DeepSeek 增强（可选）

只有希望使用在线语义增强时，才在 App 设置中填写自己的 API 接口、模型及 Key。
在线模式可能发送识别后的文字、坐标和相关页面结构信息，并产生 API 费用。
工作单位、客户或个人敏感材料应先确认是否允许发送到该服务。
不要把 Key 发给作者或写在公开反馈里；安装包没有包含作者的 API Key。

五、怎么看结果

“通过”：引擎质量检查通过，仍建议核对关键页面。
“可用但有提醒”：请阅读提醒，部分文字或图形可能仍以图片保留。
“需修正”：不是质量验收通过；先对照原稿复核并使用 App 修正，可能没有生成最终 PPTX。

可编辑覆盖率只针对引擎识别出的文字，不能保证没有漏识别。
未变成可编辑文字的区域可能仍保留为图片，不等于原文一定丢失。
本工具不承诺 100% 还原、全部对象可编辑或字体字号完全一致。

六、常见问题

提示缺少 LibreOffice：安装并正常启动一次 LibreOffice 后，重新打开本工具检查。
Intel Mac / Windows 无法运行：本包仅为 Apple 芯片 Mac 版本，不是通用安装包。
字体或换行不同：先对照原文件，查看报告，在 App 中修正并重新核对。
长时间无响应：先查看应用进度和错误提示，不要反复启动相同转换；反馈时提供版本、系统和脱敏错误信息。

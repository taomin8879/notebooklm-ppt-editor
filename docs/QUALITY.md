# 如何判断转换结果可用

建议先试一页，再处理全篇。请用自制、公开获授权或已脱敏的材料测试。

| 引擎结果 | 下一步 |
| --- | --- |
| 通过 | 仍核对关键文字、数字和布局 |
| 可用但有提醒 | 阅读每项提醒，对照源页检查；部分区域可能仍是图片 |
| 需修正 | 不是验收通过，先修正再复核，可能没有最终 PPTX |

## 五项人工检查

1. 在 PowerPoint 中实际选中文字，修改一句话，确认不是整页图片。
2. 对照原稿，检查漏字、错字，特别是数字、单位和专有名称。
3. 检查换行、边缘裁切、重叠、背景残影和双层文字。
4. 检查复杂图形是否保留、能否满足本次修改需求。
5. 保存并重新打开文件，确认交付目标环境中的显示效果。

“可编辑覆盖率”只针对识别出来的文字，不等于视觉相似度，也不保证没有漏识别。自动检查通过不替代人工验收。

## 反馈模板

- App 版本、macOS 版本、芯片。
- 输入格式、总页数、出问题的页码。
- 使用本地还是在线模式（不要提供 API Key）。
- 预期结果、实际结果、脱敏错误与对照截图。

不要上传无权公开的原始报告；可以用自制页面复现相同问题。
